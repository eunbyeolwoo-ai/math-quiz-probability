# 중학교 2학년 수학 퀴즈 웹앱 - 경우의 수와 확률

중학교 2학년 2학기 수학 과정의 **경우의 수와 확률** 단원을 복습하고 점검할 수 있는 인터랙티브 웹앱입니다.
별도의 서버나 외부 라이브러리 설치 없이, `index.html` 파일을 더블 클릭하기만 하면 교실 TV(전자칠판), 컴퓨터, 스마트폰 어디서든 즉시 실행할 수 있습니다.

---

## 🌟 주요 기능 및 특징

1. **20문항 4지선다형 퀴즈 (중2 교육과정 맞춤)**
   - **경우의 수 (합의 법칙, 곱의 법칙)**: 주사위, 카드 뽑기, 음식 고르기, 동전 던지기 등
   - **줄 세우기 및 대표 뽑기**: 자격이 다른 경우 vs 자격이 같은 경우
   - **자연수 만들기**: 0을 포함한 숫자 카드 문제
   - **확률의 뜻과 성질**: 0 이상 1 이하, 절대로 일어나지 않는 사건
   - **여사건의 확률**: 비가 오지 않을 확률, 동전에서 '적어도 하나는 앞면'
   - **확률의 계산**: 덧셈 및 곱셈, 가위바위보, 다시 넣지 않는(비복원) 연속 추출

2. **한 문제씩 집중 진행 & 즉각적인 피드백**
   - 보기를 고르면 정답 여부(초록 체크 / 빨간 엑스)가 즉시 표시됩니다.
   - 오답을 골랐을 경우 정답 보기가 함께 안내되어 직관적인 학습이 가능합니다.
   - **한두 문장으로 정리된 쉬운 핵심 해설**이 바로 나타납니다.

3. **교실 TV & 스마트폰 반응형 디자인**
   - 교실 뒷자리에서도 또렷하게 볼 수 있는 고대비 타이포그래피.
   - 상단의 **[📺 교실 TV 모드]** 버튼을 누르면 1단계/2단계로 글자 크기가 더욱 확대됩니다.
   - 스마트폰 화면에서도 손가락으로 누르기 넉넉한 터치 영역 지원.

4. **교실 수업용 편의 기능**
   - **키보드 단축키 지원**: 숫자 `1`, `2`, `3`, `4` 키로 보기 선택, `Enter` 또는 `Space` 키로 다음 문제로 바로 이동 (무선 프리젠터/에어마우스 호환).
   - **내장 효과음 (사운드)**: 외부 파일 다운로드 없이 브라우저 자체 Web Audio로 명쾌한 효과음 제공 (상단 버튼으로 음소거 가능).
   - **최종 결과 & 오답 노트**: 100점 만점 기준 점수, 만점/고득점 시 축하 콘페티 효과, 틀린 문제만 모아서 복습할 수 있는 오답 노트 제공.
   - **다시 풀기**: 언제든지 처음부터 다시 도전 가능.

---

## 🚀 실행 방법

- `index.html` 파일을 웹 브라우저(Chrome, Edge, Safari 등)에서 더블 클릭하여 실행합니다.
